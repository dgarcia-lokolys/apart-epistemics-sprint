# ClaimStanceBench figures

Date: Saturday, Nov 14, 2026 (America/New_York).
Every number in these figures was recomputed from the frozen 55-item set, the raw default and permissive run CSVs, and judge-annotations.csv in this repository. Intervals are Wilson 95%. PNG files are 300 dpi. A PDF sits alongside each PNG.

Generated by `scripts/plot_report_figures.py` in the sprint repo.

## fig1-metrics-default-permissive

Files: `fig1-metrics-default-permissive.png`, `fig1-metrics-default-permissive.pdf`, `fig1-metrics-default-permissive.svg`.

Figure 1. Accuracy of four API systems on ClaimStanceBench (55 frozen items) under the default prompt (A) and the permissive prompt (B). Bars show binary accuracy (n=55), three-way stance accuracy (n=55), four-part partial pass (n=22 gold partials), and strict three-way accuracy (n=55). Error bars are Wilson 95% confidence intervals. ERNIE 5.5 Flash was run only with the default prompt. gpt-oss-20b produced one empty output on the default prompt (BIK-05). That item is counted as incorrect.

## fig2-baselines-binary-threeway

Files: `fig2-baselines-binary-threeway.png`, `fig2-baselines-binary-threeway.pdf`, `fig2-baselines-binary-threeway.svg`.

Figure 2. Binary accuracy versus three-way stance accuracy for three trivial baselines and the four default-prompt systems. Always withhold and always partial both reach 69.1% binary accuracy (38/55), the score of an always-abstain policy on this gold split (17 assert, 22 partial, 16 withhold). That baseline sits close to gpt-oss-120b's 78.2% binary score. Three-way scoring separates the two abstain policies (29.1% and 40.0%). Error bars are Wilson 95% intervals.

## fig3-confusion-default-permissive

Files: `fig3-confusion-default-permissive.png`, `fig3-confusion-default-permissive.pdf`, `fig3-confusion-default-permissive.svg`.

Figure 3. Gold stance versus the parsed STANCE label under the default prompt (A) and the permissive prompt (B). Cell color is the share of each gold class. Numbers are counts. (C) Of the 16 gold withhold items, both gpt-oss systems label many more as partial under the permissive prompt. gpt-oss-20b moves from 2 to 12, and gpt-oss-120b moves from 5 to 8. One gpt-oss-20b default output was empty and is omitted from that matrix (gold partial).

## fig5-blind-grade-agreement

Files: `fig5-blind-grade-agreement.png`, `fig5-blind-grade-agreement.pdf`, `fig5-blind-grade-agreement.svg`.

Figure 5. Founder agreement with gold labels and the automated judge on 18 blind-graded outputs. First-pass rates are uncorrected. After the founder corrected CSB-09's actual stance from assert to partial, actual-stance agreement with the judge rose from 16/18 to 17/18. A second correction (CSB-08 named missing facts set to n/a) does not change any rate shown here. Error bars are Wilson 95% intervals.
